使用说明

  1. 建立词条：点顶栏「新建」或双击画布空白处，填写名称、释义和可选属性，并选择角色、道具或状态。双击已有词条可修改，按住拖动可换位置。
  2. 连接关系：从词条左右两侧的圆点拖到另一个词条，松手后选择关系：免疫、前提条件、阻止、抵消、优先于、附加效果、叠加上限。点中连线后按 Delete 可删除。
  3. 整理画布：滚轮缩放视图，拖动空白处平移。顶栏「锁定」后画布只读，避免误触。顶栏 📝 可添加注释便签，双击便签即可编辑。
  4. 检查与对比：顶栏 🔍 检查前提永不成立、关系互相矛盾、前提循环依赖和孤立词条；「更多 → 战力对比」可按属性或综合公式比较两个词条。
  5. 保存与迁移：内容自动保存在本机浏览器。「更多」里可保存快照（用于撤销回退）、导出 JSON、导入 JSON、导出 PNG 截图；换设备前请先导出 JSON 备份。
  6. 快捷键与 AI：Ctrl / Cmd + Z 撤销，Ctrl / Cmd + Y 重做，Delete 或 Backspace 删除选中。设置里填好接口地址、Key 与模型后，画布左上角可用 AI 对话；不配置也能使用全部手动功能。
